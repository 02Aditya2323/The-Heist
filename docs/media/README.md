## Generation prompt

Use case: ads-marketing. Create a compact wide GitHub repository header banner, aspect ratio 3:1, for THE HEIST, a real-time multiplayer cybercity game with an authoritative server. Original editorial graphic, not a website screenshot or full cinematic city poster. Dark ink navy background, refined gold and cyan accents. Left half: bold angular polished title text exactly "THE HEIST", smaller subtitle exactly "A REAL-TIME MULTIPLAYER WORLD". Right half: a small elegant isometric district diorama, tiny human operator silhouettes connected by sparse cyan network lines and geometric spatial cells, suggesting a shared city and server engineering. Restrained warm building lights, lots of negative space, crisp readable composition, premium game engineering identity. No buttons, no dashboard, no metrics, no extra text. Deliver a shallow horizontal banner.
